# Nota Skill

This repository distributes the official [Nota](https://nota.ona.cool) Agent Skill.

Install it globally with:

```sh
npx skills add ask-well/nota -g
```

For a project-level installation, omit `-g`.

The Skill is authored in [`weworklabs/nota`](https://github.com/weworklabs/nota/tree/develop/skills/nota) and published here automatically after its release checks pass. The `main` branch is the latest release source. Changes made only in this repository may be overwritten only after a maintainer resolves the resulting publication drift.

See the [official installation page](https://nota.ona.cool/skills/nota) for the universal ZIP and Coding Agent prompt.
